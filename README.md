# 帧语智能编辑器 WebAV Demo

浏览器本地视频编辑 Demo：导入多个 MP4 视频素材，将其按顺序加入单一视频轨；再添加 MP3/WAV 背景音乐或音效、手动字幕，在 WebAV 画布预览后导出烧录字幕和混音的 MP4。媒体不会上传到服务端。

## 启动

当前开发环境的 Node 22 安装在 `/home/lth/.local/node/bin`。新终端先执行：

```bash
export PATH=/home/lth/.local/node/bin:$PATH
cd /home/lth/webav/v1.0/editor-demo
npm install
npm run dev -- --host 0.0.0.0
```

通过 VS Code Remote 的端口转发，在桌面 Chrome 或 Edge 打开 `http://localhost:5173`。首次验证使用短 H.264/AAC MP4（≤30 秒、720p）及 MP3/WAV（≤60 秒）。

## 功能范围

- 固定 1280×720 / 30 FPS / 16:9 导出；非 16:9 视频等比缩放并保留黑边。
- 素材库顶部固定提供“导入/生成视频、音乐、音效、字幕”及“从素材库导入”五个入口；仅接入本地 MP4、MP3/WAV 和手动字幕，AI 生成/ASR 均明确标为待接入。
- 素材列表可按全部、视频、音乐、音效、字幕筛选并独立滚动。音乐/音效会在工程素材数据中保留分类；音频卡片可试听本会话导入的本地文件，字幕卡片引用实际字幕片段。
- 默认提供字幕、视频、背景音乐、音效轨；可新增、重命名、排序、调整高度或删除空轨。可新增多条视频轨：同一视频轨禁止片段重叠，不同视频轨可同时播放并叠加。
- 视频轨按 `Track.order` 从下到上映射为递增 `zIndex`，较后的视频轨覆盖较前的视频轨；字幕固定在全部视频图层之上。
- 轨道标签列固定在左侧，轨道内容独立纵向滚动；标尺与片段区域横向同步，时间零点始终在标签列右侧 110px。
- 素材库、预览、属性栏以及底部时间轴可拖拽调整尺寸，双击分隔条恢复默认。面板尺寸只保存在当前浏览器会话。
- 同一视频素材可多次引用。工程时长只由视频片段的最晚结束时间决定，音频和字幕不会延长画面。
- 音频/字幕支持 100 ms 吸附移动、左右裁剪；音频裁剪使用 `AudioClip.split`，不是单纯缩短时间轴矩形。
- 可从素材面板手动输入字幕文本、起止时间；右侧可继续编辑字幕文字、样式、位置、时间及音频起点、时长、音量。
- 视频片段可在视频轨内移动、跨视频轨移动、左右裁剪和删除；删除不触发波纹移动。视频裁剪复用 WebAV 的 `MP4Clip.split` 路径，画面与原声始终使用同一源区间。
- 视频属性支持全画面、右上角画中画、1280×720 内部坐标位置/尺寸、保持宽高比、透明度及原声音量/静音；可在预览框中拖动选中图层或拖动右下角缩放。
- 时间轴对音乐/音效片段显示由 WebAV PCM 生成的峰值波形，对视频片段显示由 WebAV 抽取的真实源帧缩略图。预览数据按 Asset 缓存；裁剪片段按其源文件区间显示，不影响预览或导出媒体。
- 当前不包含转场、遮罩、色度抠图、关键帧动画、自动字幕、FFmpeg、云端保存、撤销重做、波形或移动端适配。

## 架构

- `src/editor`：工程数据、编辑命令与时间计算；内部时间统一为毫秒。
- `src/editor/layoutMath.ts`：工作台最小尺寸与窗口收缩时的尺寸校正。
- `src/webav/WebAVAdapter.ts`：本地 `File` 与 WebAV 运行时对象的隔离、画布预览、音频切片、字幕位图和 MP4 输出；仅在这一层转换微秒。
- `src/App.tsx`：工作台、素材导入、属性面板和自定义轻量时间轴。连续拖拽会节流同步至 WebAV，导出前总是根据最新工程快照重建合成器。

## 检查

```bash
npm run typecheck
npm run test
npm run build
PLAYWRIGHT_BROWSERS_PATH=0 npm run test:e2e
```

远程 Ubuntu 无 sudo 权限，因此可先在项目内解包 Chromium 所需运行库，再执行：

```bash
./scripts/setup-playwright-libs.sh
npm run test:e2e:local-libs
```

该方案已使 Playwright Chromium 成功启动。但当前远程无头 Chromium 不提供完整 WebCodecs（`VideoDecoder`、`VideoEncoder`、`AudioDecoder`、`AudioEncoder` 均缺失），E2E 会明确显示为 **skipped**，而不应当当作真实导出通过。请使用本机 Chrome/Edge 经端口转发执行下列手工验证。

## 手工验证清单

1. 连续导入两个内容明显不同的 MP4；确认第二个只进入素材库，点击其“+ 视频轨”后，两个片段在同一视频轨首尾相接，且总时长等于两者之和。
2. 将片段 B 拖到片段 A 后方留出空隙，播放或跳转至拼接边界，确认片段 A 后出现片段 B、各自原声同步；空白区间应为黑色而非残帧。将 B 拖到 A 上方或将 A 的右边缘拖入 B，应被拒绝而不会产生重叠。
3. 拖动视频片段的左右白色边缘：右裁剪只改变使用时长；左裁剪同时改变工程起点与源文件起点。确认在预览及导出中画面和原声都来自裁剪后的同一段源视频；删除其中一个片段后，另一个仍停留在原时间位置并可播放。
4. 新建第二视频轨，将视频 B 加入该轨并设为 2 秒开始；选择 B 后点击“画中画”，确认 0～2 秒仅有 A，2 秒后 B 位于右上角。拖动 B 的预览边框和右下角手柄，或修改 X/Y/宽高/透明度，确认预览立即变化且重新跳转后保持一致。
5. 将两个视频轨上下排序，确认较后视频轨覆盖较前视频轨；把 B 跨轨移动，确认素材源区间、画面布局和时间保持。尝试在同一视频轨重叠两个片段，应被拒绝。
6. 分别修改 A、B 原声音量并将一条静音；叠加背景音乐、音效和字幕后试听。导出的 MP4 应保留正确的画面层级、两条视频原声混音、外部音频和字幕。
7. 在音乐、音效轨添加 MP3/WAV，确认片段内出现真实波形；静音段接近零，高振幅段较高。左右裁剪后，波形应切换到相应的源音频区间；缩放、改变轨高、纵向滚动与拖拽操作都不应使波形遮挡手柄。
8. 在视频片段中确认出现真实缩略图；从同一视频添加两个不同源区间时，两个片段缩略图应对应不同时间段。缩放、裁剪、跨视频轨移动和删除其中一个引用不应使另一个片段的缩略图消失。
9. 拖动三条工作区分隔条，双击分别复位；缩放中央区时确认预览画布等比显示，视频实际输出尺寸仍为 1280×720。
10. 检查素材面板顶部五个入口在滚动素材列表时保持不动；切换全部/视频/音乐/音效/字幕筛选，确认列表独立滚动。导入音乐、音效后确认分类色彩、试听和相应添加按钮正常；“生成待接入”不得产生伪造结果。
11. 通过“导入/生成字幕”输入文字与起止毫秒，创建后确认字幕卡片、时间轴、右侧属性与画布使用同一真实字幕片段。
12. 新增 10 条以上字幕/音乐/音效轨，调整部分轨高并上下滚动；确认标签、片段、网格和播放头仍对齐，横向滚动不影响纵向位置。
13. 新增两条背景音乐轨和两条字幕轨；将片段拖到同类型轨，确认时间、素材及字幕样式不变。预览和导出应同时包含所有音频、字幕片段。
14. 导入 MP3 和 WAV，分别添加为背景音乐与音效，移动到不同时间位置并确认可叠加播放。
15. 添加字幕，编辑文字、颜色、字号、位置和时长，确认预览与时间轴同步。
16. 右、左裁剪音频后确认听到的音频源内容确实改变；调整音量后确认预览变化。
17. 导出，重新播放 `frameyu-demo.mp4`，确认两段视频及各自原声、两类音频和字幕的时间/位置；输出时长应与视频片段最晚结束时间一致。

详细 API 和阶段测试记录见 [`docs/verification.md`](docs/verification.md)。

## 当前阶段

当前分支为 `phase5-waveform-thumbnails`。本轮完成可调工作台、动态轨道、素材面板、多视频轨叠加、画中画、音频波形与视频缩略图。远程真实多视频和多轨音画导出仍因无头 Chromium 缺少 WebCodecs 而未验收；在本地 Chrome/Edge 清单完成前，不应将其标记为通过。
