# 帧语编辑器：Windows 操作说明

本次上传保留 Editor 和 Studio 两个入口，不迁移、不合并界面。已验证的是本机编辑、MP4 导出和无密钥 Mock 流程，真实 DeepSeek / GLM API 尚未验证。

## 1. 获取项目与安装依赖

可以在 GitHub 点击 **Code → Download ZIP**，解压后进入含 `package.json` 的目录。不要在压缩包内部双击启动脚本，也不要覆盖旧项目。

已安装 Git 时，也可以在 PowerShell 运行：

```powershell
git clone https://github.com/rong-24/frameyu-webav-editor.git
cd frameyu-webav-editor
```

安装包含 npm 的 Node.js 22.10 或更新版本，然后重新打开 PowerShell，在项目目录执行：

```powershell
node --version
npm.cmd --version
npm.cmd ci
```

`node_modules` 不随源码上传；首次下载项目必须安装依赖。已有旧项目的本机目录联接只用于开发复用，不是其他电脑的安装方式。

## 2. 启动、打开与停止

无密钥演示：双击根目录的 **`start-ai-mock.cmd`**，或执行：

```powershell
npm.cmd run dev:ai:mock
```

启动成功后用桌面 Chrome / Edge 打开 **http://127.0.0.1:5173/**。启动器同时运行前端（5173）和本机代理（8787），窗口需保持打开。停止时在启动窗口按 **Ctrl+C**。单独运行 `npm.cmd run dev` 只会启动前端。

| 地址 | 用途 | AI 助手 |
| --- | --- | --- |
| `/` | 首页，点击“创作”进入 Studio | 无 |
| `/studio` | Studio 工作台，含原创示例、导入、预览、时间线和导出 | 有，默认 Mock |
| `/editor` | GitHub 原版编辑界面，含素材抽屉、多轨、裁剪、属性编辑和导出 | 本版未接入 |

两边共用底层引擎，但**当前工程不在页面之间同步**。开始演示后留在所选工作台；刷新或关闭页面会丢失本次内存中的工程和媒体引用，需重新导入。`stdio` 是代码里的标准输入输出，与 `/studio` 页面不是同一个概念。

## 3. 组会演示：Studio 无密钥智能剪辑流程

1. 从首页进入“创作”，等待示例载入；也可以打开 `/studio`。
2. 点击“导入本地素材”，导入短 H.264 MP4。无需额外下载时，可选择仓库自带 `public/demo/coast.mp4`，输入 **“剪成 2 秒，加一个标题，降低原声”**。要求 20 秒时，请选总可用时长至少 20 秒的素材。
3. 打开 **AI 助手**，确认模式是 **Mock · 本机规则测试（无 AI）**，勾选 1–3 个视频。导入不会自动选中 AI 素材。
4. 输入要求，点击 **“1. 在本机抽帧（不上传）”**。核对每素材 3 张图片及时间戳。
5. 点击 **“2. 确认运行 Mock 测试”**。数据仅交给本机代理；没有发给 GLM 或 DeepSeek。Mock 使用确定性规则，不能识别画面、主要内容或语音。
6. 审阅具体素材、源起止毫秒、拼接顺序、文字及音量。此时原时间线未改变。
7. 点击 **“3. 确认替换时间线”**。它会替换全部原片段，包括原音乐和字幕，保留素材库。应用后的剪辑直接进入真实 WebAV 时间线。
8. 点击播放检查效果。顶部 **“撤销”** 一次恢复整批计划，**“重做”** 可以再次应用。若生成后手动改过工程，须重新抽帧生成方案。
9. 点击 **“导出视频”**，填写文件名、选择浏览器下载或系统保存位置，再点击 **“开始导出”**。输出 MP4，1280×720、30 FPS；导出后用播放器检查画面和声音。

可支持的 AI 计划操作：截取、顺序拼接、标题/文字叠加、原声音量调整。没有语音识别；文字必须是用户文字或标注为生成文案。没有转场、自动配乐或完整视频理解。

## 4. Editor 手动编辑

1. 打开 `/editor`，从素材区上传视频、音乐或音效。第一个视频自动放到时间线；后续视频先进入素材库，点击卡片 **“+ 视频轨”** 加入。
2. 在素材抽屉中按类别浏览。相同文件内容会去重；同一素材仍可多次加入时间线。云素材与云保存入口为未接入占位。
3. 选中时间线片段，在右侧调整起止范围、音量、视频位置/尺寸和播放速度；可以分割、跨兼容轨移动、排序轨道或调整轨道高度。
4. 裁剪画面时在预览区域修改裁剪框，然后明确确认或取消。裁剪未结束时不能导出。
5. 使用“添加字幕”填写文字和时间，再“创建字幕”。此操作不识别语音。
6. 播放预览后打开“导出视频”，确认文件名与保存方式，开始编码。

**Editor 本版没有 Studio 的 AI 面板和撤销/重做。** 不要切换到 Studio 来继续同一个工程；两边不会自动转移素材和剪辑。

## 5. 用户自行进行真实 API 联调

本节需要自己的服务商账户与额度；本次代码交付没有执行这些付费请求。

1. 停止 Mock 服务。将 `server/.env.example` **复制**为 `server/.env`，只在本机编辑密钥；已有 `.env` 时直接本机编辑，不覆盖。不要把密钥发到聊天、截图、GitHub 或浏览器中。
2. 填写 `DEEPSEEK_API_KEY`、`GLM_API_KEY`。GLM 使用标准模型 API 密钥，不是 Coding Plan 专用接口。模型名与超时等配置见模板，按账户权限与官方文档核对。
3. 双击 **`start-ai-real.cmd`**，或执行 `npm.cmd run dev:ai`。仅真实启动会读取 `server/.env`。启动真实后端不等于已经调用模型。
4. 进入 `/studio`，主动将 AI 运行模式改为 **“真实 API · GLM + DeepSeek”**；页面不会因为已填写密钥就自动切换。
5. 选自己允许发送的素材，先本机抽帧。核对发送说明后，主动点击 **“确认发送并调用真实 API”**。
6. GLM 接收少量图片、素材 ID 和时间戳；DeepSeek 接收要求、素材信息与 GLM 描述。完整视频、音频及原始文件名不发送到服务商。抽帧分析不代表理解全部视频，也没有语音转录。
7. 审阅计划后再应用、预览和导出。模型返回结果必须通过白名单和范围校验；没有执行模型生成代码的路径。

缺密钥不会伪装为真实成功或自动退回 Mock。

## 6. 常见问题

| 提示或现象 | 操作 |
| --- | --- |
| `'npm' 不是内部或外部命令` | 当前启动器可直接寻找已有 Node；先双击 `.cmd`。首次安装依赖仍需安装含 npm 的 Node，并重新打开终端，用 `npm.cmd ci`。 |
| 缺少 Node 或依赖 | 检查 `node --version` 是否至少 22.10，在有 `package.json` 的目录安装依赖。运行 `.\start-ai-real.cmd -Check` 只检查启动条件，不读取密钥、不启动服务。 |
| 5173 / 8787 已被占用 | 旧项目或另一个启动窗口仍在运行。先在旧窗口 Ctrl+C，再启动当前版本。不要并行启动 Mock 和真实服务。 |
| 仍看到旧页面 | 确认旧服务已停止，再启动正确目录，刷新浏览器。地址相同并不保证服务来自同一目录。 |
| 找不到 AI 助手 | 检查是否在 `/editor`；AI 本版在 `/studio`。 |
| 没有方案或按钮灰色 | 勾选 1–3 个视频，填写要求，先抽帧；工程改变后重新准备。 |
| `MISSING_KEY` | 后端未加载密钥，或启动的是 Mock 后端。按真实联调步骤在本机配置并重启。 |
| `AUTH` / `QUOTA` / `RATE_LIMIT` | 分别检查密钥/权限、余额、限流或服务商额度；不要反复提交。 |
| `NETWORK` / `TIMEOUT` / 代理不可用 | 检查本机代理窗口、网络和防火墙；仅前端启动不包含后端。 |
| `OUTPUT` | 模型结果未通过严格校验，未应用到时间线。调整要求后重新生成。 |
| 视频无法导入或导出 | 用最新桌面 Chrome / Edge，先用短 H.264 视频验证；并非所有浏览器/编码都受支持。 |

## 7. 已验证与验证命令

本次适配在 Windows 上通过 **131 项 Vitest 测试、13 项 Edge E2E、类型检查和构建**。浏览器测试包括首页滚动、两个入口、导入、预览、MP4 编码后重新解码、Mock 应用与整批撤销，以及原版裁剪像素路径和素材抽屉。

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
$env:PLAYWRIGHT_CHANNEL='msedge'
npm.cmd run test:e2e -- --workers=1
```

E2E 自动启动 5175 / 8789 的独立无密钥测试服务，不读取 `.env`，禁止请求外部模型，也不复用日常服务。构建有 JS 体积超过 500 kB 的提示，不影响构建成功。

未验证：真实 API 的账户权限、额度和输出质量；系统另存为原生对话框自动化；多种长视频裁剪导出性能；手机完整编辑体验。不要将代码/Mock 测试通过描述为真实 API 已验证。

更多配置和限制见 [Windows AI 启动说明](../WINDOWS-AI-启动说明.md)；适配文件记录见 [适配报告](INTEGRATION-20261021.md)。
